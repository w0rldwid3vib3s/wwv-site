## GitHub 101 (why this file exists)

You are looking at a **README**. GitHub shows this file automatically on the repo page. It is the product’s welcome mat.

| Word | Meaning here |
| --- | --- |
| **Repository** | This whole project (`wwv-site`) |
| **Commit** | One saved snapshot with a message, like “add catalog” |
| **Branch `main`** | The live, trusted copy of the files |
| **Public** | Anyone with the link can read this. Do not put secrets here. |

Private planning lives in a different repo: `wwv-studio` (not public).

## How WorldWideVibes uses GitHub

1. **GitHub is the warehouse.** Chats are conversation. GitHub is the copy that still exists tomorrow.
2. **One repo per product.** Hollowpath does not live inside this catalog repo.
3. **This repo is public on purpose.** Build-in-public means a real URL people can open.
4. **Releases come later.** When a product ships a version (`v1.0.0`), GitHub can attach a downloadable release.
